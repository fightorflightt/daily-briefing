# 公众号夜读

只发布公众号文章标题、公众号名称和原始链接，支持日期回看与搜索。每天北京时间23:00由本机Codex自动化发布当天已经同步的公众号日报。

界面保持白底简洁列表：左侧固定日期导航，日期倒序、最新在最上面；右侧显示当天文章。默认打开最新日期，不添加宣传区、装饰图案或其他资讯栏目。

每天详情页的文章列表上方展示一段中文总结，概括筛选后资讯中的政策法规、会议部署和具体机会。导出时由scripts/summary.mjs生成并写入当天JSON的summary字段，切换日期随之切换；搜索仅筛选下方文章，不改变当日总结。总结只依据收录标题，不补写原文未提供的措施、资格、期限或成效。

网站：https://fightorflightt.github.io/daily-briefing/

导出命令：`node scripts/export.mjs <笔记库绝对路径> [YYYY-MM-DD]`。

来源仅限 `6-资讯/gongzhonghao/YYYY-MM-DD.md`，由已有微信读书 weread_mp 流程采集。文件缺失或无有效文章时保留上一期并报告。

网站选题聚焦政策法规、制度变化、重要会议及其部署、产业扶持、补贴申报、招录人才等具体机会。不因来自官方公众号就全部收录；排除健康养生科普、人物文化故事、文旅风景、生活猎奇、纪念捐赠、获奖宣传、天气快讯和已结束报名等内容。用户明确排除弘一大师/游本昌故事、广州花海文章。

`scripts/filter.mjs` 在导出时根据标题和链接初筛，保留原始日报以便回溯。不把标题初筛当成阅读全文核验，不补写未读原文的摘要、资格或截止日期。导出日志记录逐条理由和保留/过滤数量；若原始日报有效但全被过滤，可正常生成当天零条的版面，无需凑数。

定时发布需要生成机上的Codex自动化能运行、网络可用且当天公众号日报已生成。已发布页面可以随时在其他设备访问。
